WINDOWS TERMINAL CUSTOMIZER — RU
Автор: Disooloo

Подробная инструкция: откройте README.md

Кратко:
1. Распакуйте архив целиком.
2. Запустите WindowsTerminal.bat.
3. Меню: темы Terminal, шрифт, темы Oh My Posh, установка Oh My Posh, сброс.

После выбора темы Oh My Posh полностью закройте Windows Terminal и откройте снова.

Каталог тем Oh My Posh: https://ohmyposh.dev/docs/themes
